 Получение KEYSTORE_BASE64 и KEY_ALIAS

  1. Создать keystore (если его ещё нет)

  keytool -genkey -v \
    -keystore hookah-order.jks \
    -keyalg RSA \
    -keysize 2048 \
    -validity 10000 \
    -alias hookah-order

  Команда задаст вопросы: пароль keystore, имя, организация и т.д. Заполни или жми Enter для пропуска.

  KEY_ALIAS — это значение флага -alias, в примере hookah-order.

  ---
  2. Если keystore уже есть — посмотреть алиас

  keytool -list -v -keystore hookah-order.jks

  В выводе будет строка Alias name: ... — это и есть KEY_ALIAS.

  ---
  3. Получить KEYSTORE_BASE64

  base64 -w 0 hookah-order.jks

  Скопируй вывод целиком — это и есть KEYSTORE_BASE64.

  На macOS флаг другой:

  base64 -i hookah-order.jks | tr -d '\n'

  ---
  4. Что куда вставлять

  Обычно эти переменные идут в паре с двумя другими:

  ┌───────────────────┬──────────────────────────────────────────────────────┐
  │    Переменная     │                       Что это                        │
  ├───────────────────┼──────────────────────────────────────────────────────┤
  │ KEYSTORE_BASE64   │ base64 от .jks файла                                 │
  ├───────────────────┼──────────────────────────────────────────────────────┤
  │ KEY_ALIAS         │ алиас из -alias при создании                         │
  ├───────────────────┼──────────────────────────────────────────────────────┤
  │ KEY_PASSWORD      │ пароль для ключа                                     │
  ├───────────────────┼──────────────────────────────────────────────────────┤
  │ KEYSTORE_PASSWORD │ пароль для keystore (часто совпадает с KEY_PASSWORD) │
  └───────────────────┴──────────────────────────────────────────────────────┘
